# Технические исправления dev — 11 сентября 2026 года

Исходная ветка feature/parser-nucleotide-manifest, commit 257bf56. Main и
production не изменены. Пользователь подтвердил сохранение биологических правил
и использование latest MMseqs2 (master).

## Изменения

- Отдельные dev project/service/image, настраиваемый host-порт и dev Nginx шаблон.
- Один ASGI worker, общий лимит двух job, дисковые API-операции вне event loop.
- Running после рестарта становятся failed, queued возобновляются. Родитель
  защищён от удаления на время queued/running потомка. Фоновые задачи удерживаются
  до завершения. Реестр читает v1/v2 и пишет явно обозначенную v2.
- ID новых записей учитывает animal и полный относительный путь; дубликаты
  проверяются до записи. В FASTA восстановлены путь и описание имени.
- Other включён отдельным пакетом MSA, singleton имеет `.aln` без Clustal.
  Внутри цепи вход сортируется по исходному имени файла.
- Производные job имеют собственные log, report, manifest, оба FASTA, MSA и
  `alignment.json`, поэтому открываются и скачиваются независимо от родителя.
  Ошибки Clustal учитываются, пользовательские исключения отделены от ошибок
  обработки. Счётчик последовательностей отражает фактический MSA; полный
  провал — failed. Даже небезопасный или исчезнувший каталог job переводит
  производную job в `failed`, если запись реестра доступна.
- Legacy ID одинаковы на клиенте/сервере. Белок старой job восстанавливается из
  MSA, неизвестный источник/DNA не угадываются. Поле msa_id связывает legacy ID
  с FASTA-токеном. Уже повреждённые старые наборы с дубликатами ID отклоняются.
- Проекция CDR линейная через порядок остатков с проверкой неизменности белка;
  пустые колонки производной панели удаляются совместно для seq/numbering/cdr.
- Viewer игнорирует запоздалые ответы чужих запросов, блокирует повторную отправку,
  возвращает исключённые строки из исходного набора и сохраняет старый MSA при ошибке.
- Ссылки и отчёт используют активную версию, включая undo/redo. Экспорт панели
  сохраняет ручной порядок. Предупреждение partial входит в историю результата.
- Заглушка кластеризации сохраняет состояние viewer при возврате. Частоты
  предварительно вычисляются за один проход. Polling статуса независим от лога.

## Проверки

Успешны импорты изменённых backend-модулей и FastAPI приложения (Python 3.12),
tsc --noEmit, npm run build (TypeScript/Vite), разбор dev Compose через config.
Diff проверен на пробелы; parser/naming, production Nginx и main не изменены.

Тесты, пользовательские сценарии и вычисления ANARCI/Clustal не запускались по
действующему правилу. Docker daemon локально недоступен: сборка образа, проверка
его утилит и deployment на сервер не выполнялись. Исправления legacy, restart,
partial, возврата строк и конкурентности основаны на статическом анализе;
вычислительная проверка остаётся необходимой после разрешения пользователя.

MMseqs2 остаётся latest по решению пользователя; новая upstream-версия в этом
сеансе не скачивалась и не объявляется проверенной. Кластеризация и V(D)J остаются
подготовительными этапами. Сырая DNA не объявляется проверенной проекцией кодонов.
ANARCI CSV производной job не пересоздаются; аннотации сохранены в alignment.json.
