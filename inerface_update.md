# Изменения графического интерфейса

Статус: изменения интерфейса реализованы. Четвёртый файл выравнивания пока не
создаётся pipeline, поэтому на странице остаются три реальные кнопки скачивания
`.aln`; фиктивная четвёртая кнопка не добавляется.

## 1. Блок «Результаты выравнивания»

- Убрать кнопку «Скачать report.json».
- Скрыть полностью блок «CSV нумерации ANARCI», включая запрос списка CSV и
  кнопки скачивания. Backend-артефакты и API не удалять.
- В блоке скачивания оставить четыре кнопки выравниваний. Текущая реализация
  содержит три файла: `vheavy.aln` (VHeavy и VHH), `vkappa.aln`,
  `vlambda.aln`; четвёртый файл выравнивания пока не формируется. Перед
  реализацией нужно зафиксировать, каким именно должен быть четвёртый
  артефакт. Не создавать фиктивную кнопку.
- «Отчёт по входным/выходным файлам» (`AlignmentExclusions`) оставить без
  функциональных изменений.

Затрагиваемый компонент: `frontend/src/components/JobResults.tsx`.

## 2. Пустые группы выравнивания

В `AlignmentViewer` не рендерить карточку группы, если
`group.sequences.length === 0`. Не заменять её сообщением «В этой группе нет
последовательностей».

Затрагиваемый компонент: `frontend/src/components/AlignmentViewer.tsx`.

## 3. Полноэкранный просмотр выравнивания

- Добавить в заголовок `AlignmentViewer` кнопку «Открыть в новой вкладке».
- Кнопка открывает отдельный URL приложения для выбранной job.
- Новая страница показывает только viewer во всю доступную область окна.
- Переключатель схем IMGT/Kabat/Chothia и данные выравнивания должны работать
  так же, как на основной странице.
- За основу дизайна и функционала полноэкранного режима взять компонент
  `AlignmentViewer` из проекта mabseq:
  `A:\\projects\\mabseq-server\\mabseq-server\\Auto-mAbSeq-Server_docker\\frontend\\src\\components\\AlignmentViewer`.
  Адаптировать его к данным и API AlignMabZoo, не копируя бизнес-логику
  обработки последовательностей из другого проекта.
- Дизайн и дополнительные инструменты полноэкранного режима будут отдельной
  последующей задачей.

Потребуются: отдельный маршрут/режим в `frontend/src/App.tsx` и новый
компонент страницы либо режим `AlignmentViewer`.

## 4. Журнал выполнения

- По умолчанию журнал свёрнут.
- В свёрнутом состоянии отображается только заголовок «Журнал выполнения».
- По клику на заголовок блок разворачивается и сворачивается; индикатор
  раскрытия располагается справа.
- При раскрытии сохраняются текущие polling, прокрутка к концу журнала и
  сообщения об ошибках.

Затрагиваемый компонент: `frontend/src/components/JobStatus.tsx`.

## 5. Архив задач и текущая job

- Убрать список «Задачи» с главной страницы.
- Создать отдельную страницу «Архив задач», содержащую существующий список
  завершённых и прошлых job с выбором результата.
- Для job в статусах `queued` и `running` показывать на главной странице
  отдельную полосу статуса выполнения. Она использует существующий polling и
  `JobStatus`, но не смешивается с архивом.
- После завершения job остаётся доступной в «Архиве задач».
- Навигация между главной страницей и «Архивом задач» должна быть явной и
  сохранять прямое открытие результатов выбранной job.

Затрагиваемые компоненты: `frontend/src/App.tsx`,
`frontend/src/components/JobList.tsx`, `frontend/src/components/JobStatus.tsx`;
понадобится компонент страницы архива или лёгкая маршрутизация.

## 6. Удаление журнала выбора

Удалить из `JobWizard` весь UI-блок «Журнал выбора (что происходит
«под капотом»)», включая:

- заголовок;
- поле с текстом событий;
- локальные состояния, refs и обновления, используемые только для этого
  журнала.

Выбор животных, проектов и групп, отмена запросов и индикаторы загрузки
остаются без изменений.

Затрагиваемый компонент: `frontend/src/components/JobWizard.tsx`.

## Проверка после реализации

- Обычная страница не показывает CSV ANARCI и кнопку `report.json`.
- Пустые группы не занимают место в viewer.
- «Открыть в новой вкладке» показывает выбранную job без остального интерфейса.
- Журнал выполнения скрыт до клика и продолжает обновляться после раскрытия.
- Главная страница показывает только текущую активную job; архив доступен
  отдельной страницей.
- Журнал выбора отсутствует.
- Тесты не запускать без отдельного указания пользователя.
